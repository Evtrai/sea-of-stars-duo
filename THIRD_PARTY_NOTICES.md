# Third-party notices

Sea of Stars Duo vendors no third-party source code and bundles no third-party libraries.
The APK contains only this project's own Java and C++ (`libsosduo.so`).

At runtime the app loads, from the user's own Google Play installation of *Sea of Stars*:
the Unity engine, the game's IL2CPP code and data, and the SDKs the game ships with
(Google Play Services / Play Core, Firebase, Helpshift). None of these are redistributed
by this project. They remain under their respective owners' licences and terms.

Development tools used but not distributed: Il2CppDumper (MIT), the Android SDK/NDK.
