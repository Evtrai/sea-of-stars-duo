Sea of Stars: Thor Edition

A mockup of the dual-screen build. The top screen is the game with its HUD removed. The bottom screen carries everything the HUD and menus used to, plus a map the game never had. Switch states to see how it changes.

TOP · 1920×1080 · game only, HUD moved below

Where every panel gets its data

PanelWhat feeds itState
Party, HP, MP, goldThe game's party and stats managers, read live in memory. Portraits are the game's own sprites.working today
Lock gridEach enemy's cast: locks by damage type, which are broken, turns until it fires.data working
Live Mana, combo pointsThe encounter's Live Mana handler and combo meter, plus which combos the current points can pay for.data working
Dungeon mapSea of Stars has no dungeon maps, so the app charts one: it samples the level's walkable floor around the party and inks in rooms as you walk them. Save points, campfires, chests and exits are the level's real objects.new
ObjectiveThe destination the game's own world map flashes. The game stores a place, not a sentence, so this reads "Head to …".new
Region progressThe treasure and conch counts the game shows on its map once you own the parrot relic. Hidden until then, as in the game.new
Menu on the bottomThe game's real menu, drawn by the game engine on the second screen and driven by the controller or touch. Nothing is rebuilt, so equipping and item use behave exactly as the game intends.needs device proof

Build order

0 · Prove the second screen

Hand the engine the bottom display and get it to draw one frame there. This decides whether menus are engine-drawn or app-drawn.

1 · Clean top, new bottom shell

Hide the top HUD. Rebuild the bottom screen in the game's font and frame art with the exploring layout.

2 · Battle board

Lock grid, Live Mana, combo points and party status, switching in when a fight starts.

3 · Dungeon cartographer

Chart levels as you explore, with markers and the objective. Maps persist per area.

4 · Menus below

Party, Items, Relics and World Map open on the bottom screen while the game keeps running above.

5 · Polish

Transitions, cutscene dimming, touch, a release build and a full play session to shake it out.
